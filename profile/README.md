# Livales

**Software yang mendekatkan.**

Livales adalah perusahaan teknologi dari Indonesia. Kami membuat software yang mendekatkan kamu dengan orang-orang tersayang, dan dengan bahasa serta budaya baru.

## Produk kami

**[Kana Speed](https://kana.livales.com/id/)**
Aplikasi web gratis untuk belajar bahasa Jepang lewat kuis singkat. Sudah bisa dicoba sekarang.

**Aplikasi untuk pasangan**
Sedang kami kembangkan. Kabar selanjutnya akan kami bagikan di website.
